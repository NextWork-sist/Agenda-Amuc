# Agenda AMUC - V2

Incluye:
- Login con Supabase
- Clientes con afiliado/no afiliado
- Datos de facturación opcionales
- Búsqueda de cliente por DNI, nombre o apellido
- Alta de cliente dentro de Nueva Reserva
- Confirmación visual del cliente
- Tarifa automática: afiliado $65.000/h, no afiliado $99.500/h
- Cálculo automático de horas, incluyendo eventos que terminan al día siguiente
- Conservación de la tarifa aplicada en cada reserva

## Antes de publicar
Ejecutar `actualizacion_supabase_v2.sql` en Supabase SQL Editor.

Luego subir el contenido de este ZIP al repositorio Agenda-Amuc.
